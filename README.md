# OceanEmbed — SIH26066

Satellite-driven reconstruction of **subsurface ocean temperature** from surface observations at **0.25°** over the
**North Indian Ocean (5–30°N, 45–105°E)**, with an uncertainty + anomaly + **observation-priority** decision layer.

**Ministry of Earth Sciences · SIH 2026 · Software / Space Technology**
